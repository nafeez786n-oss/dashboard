# NRI University — Student Dashboard

A student dashboard concept created for the Group 2 College Student Dashboard assignment.

## Features
- NRI University-inspired student portal identity
- Student overview, attendance, marks and subjects
- Timetable and university notice panels
- Responsive sidebar navigation with mobile menu
- Built using plain HTML, CSS and JavaScript

## Preview
Open `index.html` in a browser.

## Important
This is an independent student project concept, not an official NRI University portal. Student name, attendance, marks, timetable and notices are demonstration data and are not connected to university systems.
